# Exchange

Standalone Python API for the simulated exchange. Public health, authenticated identity, funded REST trading and WebSocket
observations are implemented. See [funded trading](../wiki/trading-slice.md)
for allocations, exact settlement, API contracts and recovery.
See [authentication](../wiki/authentication.md) for private token configuration.

See [development setup](../wiki/development.md) and
[public interfaces](../wiki/public-interfaces.md) for commands and boundaries.
